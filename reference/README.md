# reference/

These files are read-only material from the prototype (claude.ai artifact, version 13, Sept 2026).

| File | Use |
|---|---|
| `prototype.html` | The complete working prototype in one file. Open it in a browser. The admin is hidden here (it needs the artifact runtime); see screenshots 15–17. The app code is inside `<script id="app-src">`: look up `illo()` (illustrations), `matches()`/`attrOK()` (filtering), `quickChips()`, `sortOptions()`, `renderVehicle()`, `chargingBlock()`, `renderCompare()`/`compareRows()`. |
| `catalog.json` | Full data export: 68 listings, 40 vehicle types, 39 applications, 31 spec definitions, partners. Specs are indicative, compiled from public sources (Sept 2026). **Partners, contacts, benefits and docs marked `demo: true` are fictional** and are for development only. |
| `catalog-types.ts` | TypeScript types for `catalog.json` |
| `design-tokens.css` | Colour, shadow, radius and font tokens (light and dark) |
| `screenshots/` | 01–03 browse (cards, list, by job) · 04–08 vehicle page (partner, specs, charging, contact, free machine) · 09 compare · 10 for manufacturers · 11 dark · 12–14 mobile · 15–17 admin |

Photos: the prototype uses illustrations only. Real photos need permission from the manufacturer (press kits usually allow editorial use with credit). Store the credit and licence with each image.
